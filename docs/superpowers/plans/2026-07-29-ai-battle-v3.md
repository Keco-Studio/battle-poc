# AI Battle V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the GDD-complete local V3 loop with optimistic pixel-RPG presentation, Keco-authored static content, real 8-frame PixelLab animation assets, deterministic dual-AI combat, and replayable reports.

**Architecture:** A bounded V3 runtime becomes the default route while the existing application remains available at `/legacy`. Pure TypeScript owns content validation, battle state, behavior-tree Patch validation, replay, and progression; Phaser owns world presentation; React owns preparation, spectator, and report surfaces.

**Tech Stack:** Next.js 15.1.9, React 19, TypeScript 5 strict mode, Phaser 3.80.1, Zod 3.24.1, Tailwind CSS 3.4, Vitest 2.1.9, Playwright 1.59.1, PixelLab HTTP API, Keco Account MCP.

## Global Constraints

- Work only on branch `v3`, based directly on `main`; do not read or merge another branch.
- Browser runtime must not call Keco, PixelLab, Supabase, or another database.
- Standard battle has no manual combat actions and no flee Action.
- Battle takes place on a fixed 16x16 grid; exploration is a separate 32x20 field.
- Every completed Action starts the next decision Tick for both actors.
- A Patch must match `decisionTick` and `baseTreeVersion` before it can apply.
- Every character direction ships eight sequential movement frames.
- Every skill ships a 64x64 icon and an eight-frame 512x64 effect sheet.
- STYLE FORMULA must be copied byte-for-byte into every PixelLab visual prompt.
- Standard and sandbox records, rewards, and progression must remain isolated.
- Player-visible V3 copy is Chinese; identifiers and source code remain ASCII.

```ts
export function validateV3ContentGraph(content: V3Content): string[] {
  const errors: string[] = []
  for (const encounter of Object.values(content.encounters)) {
    if (!content.enemies[encounter.enemyId]) errors.push(`encounter:${encounter.id}:enemy:${encounter.enemyId}`)
    if (!content.maps[encounter.battleMapId]) errors.push(`encounter:${encounter.id}:map:${encounter.battleMapId}`)
    if (!content.rewards[encounter.rewardId]) errors.push(`encounter:${encounter.id}:reward:${encounter.rewardId}`)
  }
  for (const skill of Object.values(content.skills)) {
    if (!content.assets[skill.iconAssetId]) errors.push(`skill:${skill.id}:icon:${skill.iconAssetId}`)
    if (!content.assets[skill.fxAssetId]) errors.push(`skill:${skill.id}:fx:${skill.fxAssetId}`)
  }
  return errors
}
```
